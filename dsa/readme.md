# Data structures and algorithms in Python

Start with the **[Python algorithms notebook](python_algorithms_notebook.md)**. It combines the teaching notes into one document with worked examples, Python code, and time/space complexity.

Read in order:

1. Understand time and memory; scan a list.
2. Find, count, sort, and search items.
3. Reuse work with windows, prefix sums, and ranges.
4. Use stacks, queues, and linked lists.
5. Explore trees and graphs with BFS/DFS and dependencies.
6. Use heaps, weighted shortest paths, and greedy choices.
7. Build DP answers, explore choices, and learn optional union-find.

The handbook includes a linked table of contents, teaching prompts, and a quick-revision table. The older PDFs and diagram notes remain supplementary references.
