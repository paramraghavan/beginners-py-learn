# Quick Navigation

## Files in This Guide

### 📖 README.md - Core Concepts

Overview of test format, algorithm patterns (Two Pointers, Sliding Window, DFS/BFS, etc.), data structure reference,
time complexity guide. **Start here to understand the fundamentals.**

### ⚡ gca_cheatsheet.md - Quick Reference

Python essentials, algorithm patterns summary, difficulty indicators (⭐⭐⭐), time complexity table, edge cases checklist,
debugging tips, self-assessment. **Keep handy during preparation.**

### 🔧 common_patterns.py - Algorithm Code

34 implementations: Two pointers, sliding window, hash maps, DFS, BFS, binary search, DP, heaps, union-find, utilities.
**Study line-by-line, copy-paste ready.**

### 🏗️ data_structures.py - Implementations

Linked list, binary tree, BST, graph, stack, queue, trie with all operations and examples. **Implement these from
scratch for practice.**

### 💪 practice_problems.py - Exercises

18 solved problems: 8 Easy, 7 Medium, 3 Hard. Each with approach, solution, time/space complexity, and test cases. *
*Practice twice: first solve, then with reference.**

### 🎯 sample_test_walkthrough.md - Full Simulation

Complete 70-minute test with 3 problems, minute-by-minute timing, thought process, debugging approach, lessons learned.
**Practice with this to simulate the actual test.**

### 📚 algorithms.md - Algorithm Theory & Implementations

13 core algorithms: Iteration, Recursion, Fibonacci, Linked Lists, Binary Search, DFS, BFS, Sorting, Hash Maps, Sliding
Window, Dynamic Programming, Backtracking, Two Pointers. Each with theory, Python code, complexity analysis, and use
cases. **Deep dive into how and why algorithms work.**

## How to Use

### Quick Prep

1. Read README.md (overview)
2. Study gca_cheatsheet.md (patterns marked ⭐⭐⭐)
3. Practice 3-5 easy problems from practice_problems.py
4. Do sample_test_walkthrough.md once

### Standard Prep - when you have more time, but not enough to read it all

1. Read README.md carefully
2. Study common_patterns.py section by section
3. Practice all 18 problems in practice_problems.py
4. Understand data_structures.py implementations
5. Do sample_test_walkthrough.md
